# AutoRobot1 Chrome Extension

AutoRobot1 是一个轻量级 Chrome MV3 扩展，用来录制、编辑和回放简单的网页点击动作。

插件使用 Chrome Side Panel，点击插件图标后会打开浏览器右侧栏。右侧栏不会因为你点击网页而自动关闭，比普通 popup 更适合录制和修改脚本。

加载目录：

```text
/Users/jiangsai/Documents/Auto_Trade/chrome_extension_AutoRobot1
```

## 功能

一级目录是脚本列表：

- `执行`：按动作顺序回放脚本
- `修改`：进入脚本动作列表
- `删除`：删除脚本
- `新增脚本`：创建一个新脚本

二级目录是动作列表：

- `开始录制动作`：进入录制模式
- `停止录制动作`：停止录制
- 动作类型：点击、滚动、键盘
- 点击字段：位置 X、位置 Y、左键/右键、点击次数、停顿(ms)、偏移 X、偏移 Y
- 滚动字段：位置 X、位置 Y、滚动 X、滚动 Y、停顿(ms)
- 键盘字段：Key、Code、Ctrl、Alt、Shift、Meta、停顿(ms)
- `删除`：删除单个动作
- `保存`：保存当前脚本
- `不保存`：放弃当前修改

## 关键设计

Chrome 插件 popup 有一个麻烦点：你点网页时，popup 通常会自动关闭。

所以 AutoRobot1 不把录制中的动作只放在 popup 内存里，而是让 content script 在网页里直接写入 `chrome.storage.local`。这样开始录制后，即使 popup 关闭，你在网页上的点击也会被保存；重新点插件图标，就能看到刚录到的动作。

## 使用

1. 打开要自动化的网站。
2. 点击 Chrome 插件图标。
3. 右侧栏打开后，点击 `新增脚本`。
4. 点击 `开始录制动作`。
5. 在网页上操作：左键/右键点击、触控板/鼠标滚轮滚动、键盘按键都会记录。
6. 再点插件图标，查看动作列表。
7. 根据需要修改位置、偏移、点击次数、滚动量、按键、停顿时间。
8. 点击 `保存`。
9. 回到脚本列表，点击 `执行`。

执行脚本时，页面上会出现虚拟鼠标轨迹；点击会有扩散特效，左键是蓝色，右键是红色；滚动会显示紫色箭头；键盘会显示绿色按键提示。

## 注意

- 当前版本记录的是浏览器视口坐标，不是 DOM 选择器。
- `停顿(ms)` 是执行当前动作前等待的时间；录制时会自动记录两次点击之间的间隔，也可以手动改，比如网页加载要等 2 秒就填 `2000`。
- 如果页面布局、窗口大小、滚动位置变化，坐标可能需要改偏移量。
- 键盘回放会发送到当前焦点元素；如果要输入到某个输入框，录制脚本里最好先点击那个输入框，再录键盘动作。
- Chrome 扩展无法在 `chrome://`、Chrome Web Store 等受保护页面执行。
- 某些网站会过滤模拟点击事件，这类网站后续要升级成更强的元素定位或 DevTools 控制方案。

## 已验证

本地 mock 测试已覆盖：

- 开始录制后点击、滚动、键盘动作能写入 storage。
- 两次录制点击之间的停顿时间会写入 `waitMs`，回放时会按该时间等待。
- 停止录制后回放动作，页面按钮能收到模拟点击，页面和内部滚动容器都能滚动，输入框能收到键盘输入。
- 回放时会创建虚拟鼠标/点击特效，便于确认脚本点在哪里。
- JS 语法检查和 manifest JSON 检查通过。

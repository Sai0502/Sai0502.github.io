# Forex Factory Weekly News

这是一个标准 Chrome 弹窗插件。

你在任何网页都可以点开它，插件会在弹窗里异步抓取 Forex Factory 周历信息，不再往网页里注入浮层。

## 规则

- 周一到周五：显示本周周一到周五的重要事件
- 周六到周日：显示下周周一到周五的重要事件
- 默认只保留 `USD` + `High/Medium`
- 可在弹出面板里开启 `EUR`

## 安装

1. 打开 Chrome 扩展管理页：`chrome://extensions/`
2. 开启右上角“开发者模式”
3. 选择“加载已解压的扩展程序”
4. 选择当前目录

## 使用说明

- 点扩展图标后会自动开始获取数据
- 获取过程中会显示“正在获取中...”
- 拿到结果后直接在弹窗里展示
- 可以点击“重新获取”跳过缓存，立即重新抓取
- 如果网页数据只有少量事件，结果会标记为可能不完整，并只缓存 15 分钟
- 首次打开可能命中 Cloudflare 验证
- 如果提示验证失败，请手动打开对应周历页面完成验证，然后回到插件点“重新获取”

## 目录

- `manifest.json`：扩展配置
- `background.js`：抓取、缓存、周判断
- `popup.*`：扩展弹窗界面

# TradovateAutoLock

`TradovateAutoLock` 是一个只服务于 `https://trader.tradovate.com/` 的 Chrome 扩展。

它现在的目标很明确：

1. 按账户独立保存风控设置
2. 按账户独立监控 Equity
3. 到达盈亏阈值后，自动执行 Tradovate 的 `手动锁定`
4. 在页面上给出“账户已锁定”和“设置未锁定”的提醒
5. 让你能从 popup 里看见当前账户的运行状态，而不是看一堆全局混在一起的数据

---

## 1. 适用范围

扩展只对这个页面工作：

```text
https://trader.tradovate.com/
```

如果当前标签页不是 Tradovate 页面：

- popup 顶部会提示“当前不是Tradovate页”
- 设置项和按钮会禁用
- 不会执行任何监控或锁定动作

---

## 2. 核心概念

### 2.1 账户维度

现在这个扩展的大多数关键状态都已经是“按账户独立”的。

也就是说：

- `LFE02567750200007` 的设置
- `LFE02568079020011` 的设置

彼此独立。

一个账户里改：

- 日亏损锁定
- 日盈利锁定
- 自动扫描间隔
- 锁定周期

不会再把另一个账户一起改掉。

### 2.2 当天基准 Equity

插件不是读 Tradovate 官方 Daily PnL。

它的计算逻辑是：

```text
当前 PnL = 当前 Equity - 当天基准 Equity
```

当天基准 Equity 的定义：

- 当前交易日里，插件第一次成功读到的 Equity

### 2.3 交易日边界

当前脚本里，“PnL 基准日”按北京时间 `06:00` 切换。

也就是：

- 北京时间 `06:00` 之前，仍然算前一个交易日
- 北京时间 `06:00` 之后，进入新的交易日，重新建立新 baseline

### 2.4 设置锁边界

“锁定设置”按北京时间 `04:00` 计算到期：

- `00:00 - 03:59` 点击：锁到当天 `04:00`
- `04:00 - 23:59` 点击：锁到次日 `04:00`

## 3. 当前功能总览

### 3.1 自动监控 Equity

内容脚本注入 Tradovate 页面后，会启动监控循环：

1. 读取当前账户号
2. 读取当前账户自己的风控设置
3. 读取页面里的 Equity
4. 计算当前账户自己的 PnL
5. 把运行状态写入当前账户自己的运行态存储
6. 等待下一个扫描周期

### 3.2 自动锁定账户

当当前账户的 PnL 到达阈值时：

- `PnL <= -日亏损锁定`
- 或 `PnL >= 日盈利锁定`

插件会自动执行 Tradovate 网页上的真实点击流程：

1. 点击 `手动锁定`
2. 打开 `选择时间`
3. 选择 popup 设置中的锁定周期
4. 点击 `锁定交易`
5. 点击二次确认

### 3.3 popup 手动锁定账户

点击 popup 里的：

```text
立刻锁定账户
```

会直接执行上面同一套真实锁账户流程。

这个按钮与当前 PnL 无关。

用途：

- 你已经决定现在就停手
- 测试锁账户流程是否还能正常执行

### 3.4 锁定设置

点击 popup 里的：

```text
锁定设置
```

只会锁当前账户的设置，不会锁别的账户。

被锁的是这四项：

- 日亏损锁定
- 日盈利锁定
- 自动扫描间隔（秒）
- 锁定周期

### 3.5 “还没锁定设置”浮层

当满足下面条件时，页面会弹出：

```text
还没锁定设置
```

触发条件：

- 当前账户没有锁定设置
- 当前账户没有锁定账户
- 当前页面能找到 `手动锁定` 按钮

按钮：

- `锁定`：只锁当前账户的设置
- `不锁`：关闭本页这次提醒

### 3.6 “熔断才是保命之道”浮层

当当前账户已锁定时，页面会显示倒计时浮层：

```text
熔断才是保命之道
```

这个浮层的目的只有一个：

- 让你一眼知道：当前这个账户现在处于锁定期

关闭行为：

- 点右上角关闭：只对当前页面会话生效
- 当前页不会立刻重新弹出
- 刷新页面后，如果账户仍处于锁定状态，浮层会重新恢复

### 3.7 账户已锁定时，不再提示锁设置

现在规则是：

只要账户已锁定，就不再弹：

```text
还没锁定设置
```

原因很直接：

- 账户都锁了
- 设置锁不锁已经不影响继续下单

## 4. popup 各区域含义

### 4.1 Daily PnL

显示当前账户最近一次扫描出的 PnL。

### 4.2 下次自动扫描

显示当前账户下一次自动扫描的倒计时。

正常行为应该是：

1. 一轮扫描结束
2. 立刻写入下一轮 `nextScanAt`
3. 倒计时继续从新的秒数往下走

如果 popup 打开时发现：

- `nextScanAt` 不存在
- 或已经过期

popup 会主动请求页面内容脚本恢复监控循环。

### 4.3 设置区域

这些设置现在都是“按账户独立”：

- 日亏损锁定
- 日盈利锁定
- 自动扫描间隔（秒）
- 锁定周期

当前账户切换后，popup 会重新读取这个账户自己的设置。

### 4.4 调试候选

显示当前账户最近一次成功扫描时记录的核心文本。

通常会包含：

- 当前 Equity
- 当前 baseline
- 当前 account
- 当前 dateKey

### 4.5 调试快照

默认折叠。

需要排错时再展开。

主要用于查看当前账户的：

- accountId 识别结果
- 设置锁 key
- 运行态 key
- 锁定浮层状态
- 页面锁定判断结果

### 4.6 调试日志

默认折叠。

需要排错时再展开。

用于看最近发生过哪些动作，比如：

- 为什么没弹设置提示
- 为什么恢复了锁定浮层
- 为什么跳过了某次动作

### 4.7 功能测试（锁定账户流程测试）

这是定位 Tradovate 页面按钮位置用的测试区。

不是普通交易时必须使用的功能。

用途：

- 页面改版后微调点击位置
- 验证自动锁定流程能不能准确点到每一步

## 5. 当前存储结构

### 5.1 按账户独立的设置

```text
tradovateMonitorSettings:<accountId>
```

内容包括：

- `dailyLossLimit`
- `dailyProfitTarget`
- `scanIntervalSeconds`
- `lockDuration`
- `autoMonitorEnabled`
- `autoLockEnabled`

### 5.2 按账户独立的设置锁

```text
tradovateSettingsLockedUntil:<accountId>
```

### 5.3 按账户独立的运行态

```text
tradovateRuntimeState:<accountId>
```

内容包括：

- `lastPnl`
- `lastEquity`
- `lastPnlSource`
- `lastSeenAt`
- `lastPageUrl`
- `lastPageTitle`
- `lastCalendarCandidates`
- `nextScanAt`

### 5.4 按账户独立的自动锁定状态

```text
tradovateAutoLockState:<accountId>
```

### 5.5 按账户独立的锁定浮层状态

```text
tradovateLockoutOverlayState:<accountId>
```

## 6. 当前账户识别逻辑

插件会尽量从以下位置识别账户号：

1. 页面可见文本
2. 页面 HTML
3. `sessionStorage`
4. `localStorage`

如果仍然识别不到，就会落到：

```text
default
```

但现在涉及账户绑定的重要动作，已经尽量避免在 `default` 上误恢复。

---

## 7. 自动扫描循环当前行为

### 7.1 正常路径

每轮循环：

1. 读当前账户号
2. 读当前账户设置
3. 扫描 Equity
4. 写当前账户运行态
5. 写下一轮 `nextScanAt`
6. 定时进入下一轮

### 7.2 自恢复

如果 popup 打开时发现：

- 当前账户 `nextScanAt` 已经过期
- 或不存在

popup 会请求内容脚本：

```text
ensure monitor loop
```

也就是：

- 如果循环还活着，就维持原样
- 如果循环断了，就立刻重启

## 8. 当前产品功能点验收清单

下面这份清单就是这版产品的验收清单。

### 8.1 账户独立设置

- 两个 Tradovate 页面，两个账户
- A 改日亏损/日盈利/扫描间隔/锁定周期
- B 不应同步变化
- 切回 A，A 仍显示自己的设置

### 8.2 账户独立设置锁

- A 锁设置
- B 不应被一起锁

### 8.3 账户独立运行态

- A 的 `Daily PnL / 下次自动扫描 / 调试候选`
- 不应直接显示成 B 的数据

### 8.4 自动扫描倒计时

- 倒计时到 0 后，不应该停死
- 一轮结束后，下一轮倒计时应立刻重新开始

### 8.5 账户锁定提示

- 账户已锁定时，应显示 `熔断才是保命之道`
- 账户未锁定时，不应无故显示

### 8.6 设置提示

- 未锁设置且账户未锁时，可以弹 `还没锁定设置`
- 账户已锁时，不应再弹 `还没锁定设置`

### 8.7 浮层关闭行为

- 关闭锁定浮层后，本页不应立刻复活
- 刷新页面后，如果账户仍锁定，可以再次恢复

### 8.8 popup 调试区

- 调试快照默认折叠
- 调试日志默认折叠
- 两个复制按钮都是小按钮，右对齐
- 调试日志不再有“清空”按钮

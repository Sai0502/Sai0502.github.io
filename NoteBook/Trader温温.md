## 为什么我会从Dtfx转到订单流

#### 1. Fábio 两大核心策略

> 拍卖理论：价格总是在一个区域**反复震荡**（建立价值区）→ **跳出去寻找新的价值区**（不平衡）→ **再反复震荡**（进入/创建新价值区）

| 策略         | 适用场景 | 操作方式                     |
| ------------ | -------- | ---------------------------- |
| **均值回归** | 震荡市   | 高抛低吸，在价值区内做反向   |
| **趋势突破** | 趋势市   | 突破后跟随趋势，寻找新价值区 |

- **战术选择**：先判断今天大概率是什么行情（震荡/趋势），再决定用什么战术

  > **Fábio 80% 的交易做趋势**，因为美盘大部分时间走趋势。

- **趋势突破信号**

  1. 价格**脱离当前成交量分布**
  2. **突破**关键位置 → **回踩**确认 → **再次突破**
  3. 配合**大额订单指标** + **CVD** 双重确认

#### 2. 亚、欧、美时段

> **关键原则**：**美盘 RTH 是核心**，亚欧盘 ETH 可视为"隔夜时段"，忽略不看
>
> 1. ETH：Extended Trading Hours，延长交易时段 / 电子盘，即美股正式开盘前后，NQ期货在 Globex 上交易的更长时间段
> 2. RTH：Regular Trading Hours，正规交易时段 / 常规交易时段，即美股现货市场正式开盘对应的核心交易时段

| 时段            | 角色      | 任务                                                  |
| --------------- | --------- | ----------------------------------------------------- |
| **亚盘**        | 测试/积累 | 测试昨日美盘的 VAH/VAL，完成剩余流动性                |
| **欧盘**        | 过渡/延续 | 有时有效，但动力通常不足，可能只回到 POC              |
| **美盘（RTH）** | **核心**  | 70-80% 成交量，大资金进场，真正决定接受哪一边、往哪走 |

* [**亚盘开盘位置决定偏见**](https://www.bilibili.com/video/BV1EKADzAE2h/?spm_id_from=333.1387.upload.video_card.click&vd_source=052b07ad0190d9dabdf1d78fda0168a7)：第25分钟开始
  * 开在上/下价值区外 → 先回踩测试边界
  * 开在中间 → 大概率先震，等美盘选方向
  * 美盘开盘后 30 分钟 → 观察大资金是否接受某个价值区

* **Vol vs TPO**
  * Vol：竖着看，每根 K 线的成交量大小
  * TPO：横着看，每个价位的成交量大小 

#### 3. Daily Bias & 市场概况

> **先定偏见，再做交易**——用市场概况判断今天做震荡还是做趋势

* **Daily Bias 的重要性**

  * 没有**战略层（市场概况）**，就不能做**执行层（具体交易）**
  * 先判断"今天大概率是什么行情"，再决定用什么战术。

* **分析方法**

  * 工具：Volume Profile 成交量分布 / TPO 市场概况
  * 周期：美盘 VP（美盘集中了 70-80% 成交量）

* **具体操作**

  1. 市场概况：观察连续多日的美盘 VP，判断市场当前所处区域

     > **重叠区域** = 长期价格接受区域（重要支阻），价格到重叠区附近，大概率会停留/反应

  2. 预估今天大概率是**震荡**还是**趋势**，选择**均值回归**或**趋势突破**战术

* **开盘位置的5种情况**

  | 开盘位置           | 市场状态       | 大概率行为                 |
  | ------------------ | -------------- | -------------------------- |
  | **VAL 下方**       | 不平衡（下方） | 向上寻找边界，测试 VAL/VAH |
  | **VAH 上方**       | 不平衡（上方） | 向下寻找边界，测试 VAH/VAL |
  | **价值区内**       | 平衡           | 在区间内震荡，测试上下边界 |
  | **VAH ~ POC 之间** | 偏上不平衡     | 先测试上方，再决定         |
  | **VAL ~ POC 之间** | 偏下不平衡     | 先测试下方，再决定         |

#### 4. Delta 实战

> **Delta 看当下力量**，正负判断多空主导，接近零则观望

- Delta：一根 K 线内主动买单与主动卖单成交量的差值，反映"谁在主导市场"

  | Delta 值   | 含义                               |
  | ---------- | ---------------------------------- |
  | **为正**   | 多头主导市场，主动买入力量强       |
  | **为负**   | 空头主导市场，主动卖出力量强       |
  | **接近零** | 买卖双方力量平衡，市场在选择新方向 |

- **连续多根 K 线 Delta 为正**（如连续 16 根）→ 震荡上行，多头主导，可考虑**进场多单**做剥头皮

- **Delta 接近零** → 力量均衡，**不适合做单**，建议观望，此时做多做空都相当于预测未来，风险高

  - 即使收了阴线，若 Delta 逼近零 → 内部买卖力量平均，无需交易

#### 5. 大单（Big Order）

> **大单看机构意图**，被套住的一方 = 未来的支阻

* **核心逻辑**
  * 机构下单是为了赚钱，观察他们**是否赚到钱**
  * 若红色大泡泡（主动卖）出现，但**价格没跌反而涨** → 卖方失败，被套住，在亏钱
  * 若绿色大泡泡（主动买）出现，但**价格没涨反而跌** → 买方失败，被套住，在亏钱
* **实战**
  * 观察关键位（Key Level）的大单分布
  * 等待**一方胜出、一方失败**
  * 找到**失败方被套住的区域**
  * 当价格**回撤到该区域**时，跟随**胜方**做趋势单
* **大单 vs Delta**
  * **大单** = 大力士突然拉一下（瞬间爆发力）
  * **Delta** = 拔河中的持续发力

#### 6. 主动单 vs 被动单

| 类型       | 本质   | 特点                                 |
| ---------- | ------ | ------------------------------------ |
| **主动单** | 市价单 | 主动吃掉对方挂单，推动价格变动       |
| **被动单** | 限价单 | 挂在订单簿（DOM/市场深度）上等待成交 |

- 市场运作：**主动单吃掉被动单** → 成交 → 价格变动
- 若全是被动单，市场静止不动

#### 7. CVD（Cumulative Volume Delta 累积成交量差值）

> **CVD 看累积形势**，吸收（量破价不破）比力竭（价破量不破）更可靠

* **Delta vs CVD**

  - **Delta**：单根 K 线的成交量差值（主动买 - 主动卖）

  - **CVD**：多根 K 线 Delta 的**累积值**，拔河过程中双方**实力的总体形势**

* **两大核心形态**

  ![image-20260731184629421](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/img/202607311846655.png)

  ![image-20260731185648779](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/img/202607311856853.png)

  1. **吸收（Absorption）⭐ 更可靠**
     * 特征：CVD 跌破破了，但价格没跌破
     * 本质：主动的空头攻势凶猛，但被多方限价单接住，价格打不下去
     * 实操：最佳做多信号
  2. **能量耗尽（Exhaustion），不太可靠**
     * 特征：价格跌破了，但 CVD 没跌破
     * 含义：价格下去了，但主动的空头力量没跟上，量价不统一，跌破是假的
     * 实操：只看K线结构，会等回调做空，但这种只看价格的空不好

* **CVD + 大单结合**

  - CVD 看不到的微观吸收，大单能看出，两者结合，互相验证


#### 8. 微观订单流 vs 传统方法

| 对比项     | SMC / ICT / 趋势线   | 订单流                    |
| ---------- | -------------------- | ------------------------- |
| 买点精确度 | 模糊，可能多次止损   | 精确到具体价位            |
| 流动性识别 | 能识别但无法精确入场 | 能看到具体吸收/力竭位置   |
| 止损被扫   | 容易被假突破扫掉     | 通过 Delta/CVD 过滤假突破 |
| 本质       | 价格行为推演         | 成交量+价格双重验证       |

#### 9. 微观与宏观的一致性

> **市场在任何周期运作逻辑都相同**

- **日线级别**：一个美盘形成一个钟型曲线
- **15 分钟级别**：一段行情形成一个钟型曲线
- **单根 K 线**：每根 K 线内部也可以画出微型钟型曲线
  - 影线 = 测试边界 = 拒绝/接受
  - 实体 = 接受后的运行 = 进入不平衡态
  - 大量成交量集中在实体（POC 附近）= 平衡区

#### 10. 实战决策流程

```bash
第 1 步：日线/周线偏见（战略层）
    ↓ 用多日中盘价值区叠加，判断长期公允价值在哪
第 2 步：当日开盘位置（战术层）
    ↓ 亚盘/欧盘测试边界，观察接受/拒绝
第 3 步：美盘定方向（执行层）
    ↓ 美盘 30 分钟内观察大资金选择
第 4 步：微观入场（操作层）
    ↓ 用 Delta、CVD、大额订单确认信号，具体点位进场
```

* 价格追求效率的路径
  1. 价格脱离当前价值区（不平衡）
  2. 寻找最近的旧价值区（历史流动性）
  3. 测试 → 接受 → 继续往下一个目标
  4. 或测试 → 拒绝 → 回到原区域
  5. 原价值区也拒绝 → 价格在中间震荡，等待美盘选方向

## 如何构建复合market profile？

#### 1. Market Profile

- **本质**：市场**价值共识**的可视化

  > 价格不是在随机游走，而是在不断寻找"大家乐意交易"的区域。

  - **平衡态**：买卖双方充分交互，形成成交量/时间密集区（公允价值区）
  - **失衡态**：一方不愿意继续，价格跳出去寻找新共识
  - **长期规律**：**盘整 → 突破 → 盘整 → 突破**（任何市场通用）

- **核心问题**：钱在哪里？大家愿意在哪个价位买卖？

#### 2. 复合 market profile

* **分型（Fractal）**

  Market Profile 在任何时间框架都存在。当多个相邻周期的 Market Profile 轮廓**重叠**时，能合并成了一个**更大的价值共识区**

  ```
  [日1轮廓] + [日2轮廓] + [日3轮廓]  →  [合并后的周线级轮廓]
  [小时1轮廓] + [小时2轮廓] + [小时3轮廓]  →  [合并后的4小时级轮廓]
  ```

* **单一价值区 vs 复合价值区**

  * **单一价值区**：单周期内 70% 成交量聚集区
  * **复合价值区**：**多周期重叠合并后**的共识区
    * **优势**：能一眼看出当前处于"哪个层级的共识"中
    * **边界即关键位**：**合并价值区的 VAH/VAL 是真正的支阻，比传统画线更准**
  * **核心原则**：只做**复合价值区**。单一价值区做单很容易被扫，复合轮廓的准确率远高于单一轮廓

* **合并的方法**

  * **POC 重叠原则**

    | 情况                                 | 处理方式       | 原因                                 |
    | ------------------------------------ | -------------- | ------------------------------------ |
    | **POC 在前一轮廓的价值区内**         | ✅ **无脑合并** | 共识延续，资金在同一区域博弈         |
    | **POC 在价值区外，但之后几天回归**   | ⏳ **不合并**   | 趋势探索后回归，承认旧价值区         |
    | **POC 在价值区外，且一直在价值区外** | ❌ **不合并**   | 趋势探索未回归，属趋势日，未形成共识 |
    | **多个价值区高度重叠**               | ✅ **合并**     | 长期盘整，属同一平衡区               |

  * **详细步骤**

    * **Step 1：标记第1、2日的美盘 Market Profile**
      * 若第2日的 POC 落在**第1日的价值区 VP（VAH ~ VAL）内** → 合并
      * 若落在**VP 外** → 不合并，标记为潜在趋势日（未形成价值共识的日子）
        * 趋势日特征：量小、时间短、POC 不明显、价格单向运动
        * **处理**：**不合并**，这是"从平衡到失衡"的探索日，是失衡，不是共识
        * 用法：趋势日之后，观察价格是否在新的区域建立共识，或回归旧区域
    * **Step 2：动态补合**
      * 若第 3 日的 POC 在外 → 不合并
      * 若第 4 日的 POC **回归** 到第 1、2 日合并后的价值区内 → 把第 1~4 天**合并**
    * **Step 3：取消旧轮廓**
      * 当新的合并轮廓建立后，**旧的、被覆盖的轮廓可以取消**
      * 只保留**关键边界线**（VAH/VAL）作为历史参考

* **建立盘前偏见**：**开盘位置决定当日战术**

  | 开盘位置                       | 市场状态 | 战术                                         |
  | ------------------------------ | -------- | -------------------------------------------- |
  | **在合并价值区内**             | 平衡     | 做微观头皮，在 VAH/VAL 高抛低吸              |
  | **在合并价值区外，但靠近边界** | 测试边界 | 观察是否**接受**（回归）或**拒绝**（继续走） |
  | **远离合并价值区**             | 不平衡   | 寻找回归价值区的动能，或等待新共识建立       |

#### 实战推演

* **操作步骤**

  ```
  ① 画：每天画出 Market Profile，标 POC/VAH/VAL
      ↓
  ② 并：POC 重叠则合并，趋势日单独放，动态补合
      ↓
  ③ 用：看开盘位置 → 定偏见（震荡/回归/趋势）→ 在边界边缘做微观进场
  ```

  * **Day 1~3**：POC 重叠 → 合并（价值共识 A）
  * **Day 4**：开盘在 A 内，亚盘向上测试 VAH → **拒绝**（影线/回落）
    * **判断**：明确拒绝向上突破 → 做**回归空单**
    * 目标：A 的 POC 或 VAL
  * **Day 5~6**：POC 仍在 A 内 → 继续合并（价值共识 B）
    - **判断**：市场仍在同一共识区内震荡

  * **Day 7**：突破 VAH，POC 收在B 外 → 不做处理
    - **判断**：趋势探索开始

  * **Day 8~9**：在新的高位形成 POC，且Day 7、8、9 的 POC 重叠 → 合并（价值共识 C）
    - **判断**：新的价值共识建立，从 B → C，趋势确认

* **逻辑**

  1. 价格总是在当前价值区内震荡
  2. 突破 → 寻找下一个目标（通常是**前一个合并轮廓的边界**或**历史关键位**）
  3. 到达后测试 → 接受（形成新共识）或拒绝（回归）

### 7.14 银弹交易（ICT Silver Bullet）

1. **Session** VS **Silver Bullet**

   |          | Session                  | Silver Bullet                     |
   | -------- | ------------------------ | --------------------------------- |
   | **本质** | 各时区开放的交易时段     | 该时段内 **最值得交易的一个小时** |
   | **目的** | 界定哪个市场的资金在主导 | 捕捉机构流动性猎杀的精确时机      |

2. **Silver Bullet**

   | 时段       | 纽约时段      | 银弹窗口                                           |
   | ---------- | ------------- | -------------------------------------------------- |
   | **亚洲盘** | 20:00 – 00:00 | ICT 不做                                           |
   | **欧洲盘** | 02:00 – 05:00 | **03:00 – 04:00**                                  |
   | **美盘**   | 09:30 – 16:00 | **10:00 – 11:00**<br />14:00 – 15:00（很多人不做） |

   1. 本质：一天真正值得交易的，不是整个 Session，而是Session里面最容易发生流动性猎杀的那一个小时

   2. 真正的大资金不是全天都在干活，而是在：**机构开始大量撮合订单的时候**

      > 伦敦开盘后，很多欧洲资金开始进场；纽约开盘后，美国机构开始进场。于是，流动性开始集中

   3. 为什么不是开盘立刻交易？而是 London 等1个小时，NewYorker 等30分钟

      > 因为 ICT 认为：**开盘不是机构真正建仓的时候，而是机构"获取流动性"的时候**

      * 案例：假设亚洲盘一直在：18200~18230

        ```
        伦敦 NY 02:00 开盘
             ↓
        02:05向上冲（向下冲）
             ↓
        突破18230（跌破18200）
             ↓
        很多亚洲高点止损被打掉（很多亚洲低点止损被打掉）
             ↓
        又跌回来（再反转上涨）
        ```

      > 所以：美盘 **NY 09:30 – 10:00** 和欧盘 NY **02:00 – 03:00**： 是猎杀流动性，统一多空意见，形成真正日内结构的时间，机构会在这之后进场，更容易推动价格运行

   4. **核心**：不要死记 London 03:00，NewYorker10:00，而是记

      ```
      开盘
       ↓
      市场先收集流动性
       ↓
      再决定方向
       ↓
      Silver Bullet
      ```

      **Silver Bullet 本质上不是"开盘后的30分钟"或者"开盘后的1小时"**，而是：

      > **"开盘初期的价格发现和流动性收集大致完成后，机构更容易开始推动真正方向"**

3. **Silver Bullet 用法**

   ```
   ① 等时间窗口开始
       ↓
   ② 市场去扫流动性（例如：扫亚洲高点、扫伦敦低点、扫PDH、扫PDL）
       ↓
   ③ 出现 MSS
       ↓
   ④ 出现 FVG
       ↓
   ⑤ 回补 FVG
       ↓
   ⑥ 进场
   ```

   1. 案例：NQ，在NY 10:10，先突破PDH（诱多），随后瞬间跌回，形成MSS，留下FVG，回踩FVG，做空
   2. **只是时间筛选器**：Silver Bullet 不是让你到了 NY 10:00 就买，而是告诉你，NY 10:00 最容易出这种模型
   3. **确实能提高机会密度**： 在这些时间窗口内，市场更容易出现 AMD（流动性清扫、结构转换、快速扩张）
   4. **但真正决定是否交易的，仍然是结构**： 如果到了 Silver Bullet 时间，但没有扫流动性、没有 MSS、没有你认可的入场形态，仍不能交易

4. **Session Open Strategy**

   1. 很多交易员喜欢在 NY 21:00（亚洲开盘），03:00（伦敦开盘），09:30（纽约开盘） 开仓，这不是 **Silver Bullet**，而是 **Session Open Strategy（时段开盘策略）**

5. **总结**

   1. **Silver Bullet 不是"什么时候交易"，而是"什么时候最值得开始寻找符合你交易模型的机会"**
   2. **时间是过滤器，结构才是触发器**

6. **陷阱**

   很多人学 Silver Bullet 效果一般的原因——他们记住了"几点钟"，却忽略了真正的核心是**流动性 → 结构转换 → 入场确认**

#### 002.拍卖理论与成交量分布图

![image-20260524174552538](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260524174552538.png)

* **成交量分布图 VP（Volume Profile）核心概念**

  > 假设 70% 的成交量发生在 **平衡区** 里

  * **VAH (Value Area High)**：平衡区上轨
  * **VAL (Value Area Low)**：平衡区下轨
  * **POC (Point of Control)**：成交量最大的价格水平

* **拍卖理论核心：平衡与失衡**

  > 市场运行可以简化为两个状态的循环切换

  ```bash
     ┌───────────────┐          ┌───────────────┐          ┌───────────────┐
     │    平衡区      │  突破     │    失衡区      │  重新接受 │   新平衡区      │
     │ (Value Area)  ├─────────►│  (单边行情)     ├────────►│ (筹码再次堆积)   │
     └───────────────┘          └───────────────┘          └───────────────┘
  ```

  - **平衡（Balance）**：买卖双方对当前价格达成共识，价格在 VAH 和 VAL 之间震荡
  - **失衡（Imbalance）**：价格突破平衡区，多空平衡被打破，形成一段快速移动的**单边行情**

* **D-Shape 盘整形态**

  * 成交量分布图呈 **D 形**，POC 在中间，两侧成交量对称递减

  * 做单思路：

    * 预期：价格大概率会向筹码最密集的 POC 位置吸附

    * 计划：**VAH (高抛)** 和 **VAL (低吸)**

      > 1. VAH 和 VAL 并不是两条绝对精准的线，而是一个**范围**，即**拒绝区**（Rejection Zone）
      > 2. 价格到达拒绝区不一定会精准踩线立刻反转。而经常会制造**假突破**：向上突破 VAH 诱多后再跌回，或向下突破 VAL 诱空后再拉回

      > ⚠️ **POC 属于密集交火区，价格通常会非常混乱，在 POC 附近下单极易被无序的波动扫损**

  * 入场步骤

    1. 观察拒绝区：等待价格触及 VAH、 VAL 的拒绝区
    2. 捕捉反转信号：等待 **结构信号（MSS/CISD）** 或 **订单流反转信号** 明确的动能衰竭与反转
    3. 确认反转：价格重新回到平衡区里，且成交量开始在平衡区边缘产生堆积，代表市场重新接受此 平衡区，此时顺势进场。
    4. POC 止盈：以 **POC** 作为第一或核心止盈目标位

#### 003.VP 剧本

* **核心交易剧本**

  > VP 视角下，市场只有两种剧本：要么在平衡区内做**均值回归**，要么在突破后做**趋势跟随**，日常交易就是在两个剧本间灵活切换
  >
  > ![image-20260525000311615](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260525000311615.png)
  >
  > ```
  >                     价格所处位置
  >                          │
  >          ┌───────────────┴───────────────┐
  >          ▼                               ▼
  >     【平衡区内部】                    【突破平衡区】
  >   (VAH 与 VAL 之间)               (跌破VAL 或 突破VAH)
  >          │                               │
  >          ▼                               ▼
  >  剧本一：均值回归系统               剧本二：趋势跟随系统
  > (高抛低吸，目标看POC)            (回踩不破POC/边缘，顺势延续)
  > ```

  * **剧本一：均值回归**

    * 适用形态：买卖双方力量均衡的 D-Shape
    * 操作思路：VAH 高空，VAL低多，目标看POC

  * **剧本二：趋势跟随**

    * 适用形态：价格朝某一方向强力突破原有的平衡区的 b-Shape、P-Shape

    * 多头趋势回踩 P-Shape

      * 重点关注位置：**VAH**（第一支撑位） 和 **POC**（最后防守位）

        * 一段健康的上涨趋势，**POC 不应该被跌破**。价格最晚应该在 POC 附近受到支撑，并向上发起新一轮上涨

        * 若回调一路下跌，连续跌破 VAH 和 POC，直接跌回到 **VAL**。此时**趋势剧本失效**，行情重新回到了 **D-Shape 均值回归剧本**

          > 此时虽然在 VAL 仍可寻找做多机会，但性质已变为震荡低吸，目标只能看回 POC，而不是再期待达到趋势前高

    * 空头趋势回踩 P-Shape（逻辑同上）

      * 重点关注位置：**VAL** 和 **POC**

- **多日 VP 组合研判**

  > 通过前几天的筹码形态（D-Shape、b-Shape、P-Shape）来规划新一天的交易计划

  - 案例 A：连续多日多头趋势，即 连续 P-Shape

    ![image-20260524235003982](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260524235003982.png)

    - **背景**：前几天连续收出 **P-Shape**，表明市场处于非常健康的单边上涨趋势
    - **今日策略**
      - 延续昨日惯性，先当做 **P-Shape 趋势跟随** 处理，重点关注昨日 **VAH** 和 **POC**，伺机做多
      - 若跌破昨日 **POC**，跌回昨日 **VAL**，则 **趋势剧本失效**，进入 **D-Shape 均值回归剧本**
      - 若继续跌破昨日 **VAL**，则开始形成**潜在 b-Shape**，等回调到**昨日 VAL** 伺机做空，或者今天空仓

  - 案例 B：连续多日多头趋势后盘整，即 连续 P-Shape + D-Shape

    ![image-20260524234855501](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260524234855501.png)

    - **背景**：前几天连续收出 **P-Shape**，表明市场处于非常健康的单边上涨趋势，但昨日价格未能继续冲高，而是收出了一个 **D-Shape**，表明市场进入盘整阶段

    - **今日策略**

      1. 延续昨日惯性，先当做 **D-Shape 均值回归** 处理，在昨日 **平衡区** 内高空低多

         > * 由于整体大背景是看涨趋势，因此在**VAL 做多的赢面更高**，入场可以更激进
         >
         > * 若在上方做空，则必须等一个更完美的反转结构再入场

      2. 若突破 **昨日VAH** 或 跌破 **昨日 VAL**，则等待回调，顺着突破方向做

  - 案例 C：连续多日多头趋势后下跌，即 连续 P-Shape + b-Shape

    ![image-20260525000833886](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260525000833886.png)

    - 背景：前几天连续收出 **P-Shape**，表明市场处于非常健康的单边上涨趋势，但昨日价格不但未创新高，反而跌破 前天平衡区，收出了一个 **b-Shape**（筹码堆积在下方）

    - **如何正确解读（双重视角）**：

      - **视角1：关键位支撑（b-Shape 多头延续）**：虽然昨天收成 **b-Shape**，但它还是在 **大前天 P-Shape的平衡区上轨 VAH** 上撑住了，依然是强烈的**看多偏见**，保守看多到  **b-Shape 的平衡区上轨 VAH**

      - **视角2：大级别合并（D-Shape 均值回归）**：如果把 **前天的 P-Shape** 和 **昨天的 b-Shape** 合并，则组合成了一个**更大的 D-Shape**。由于价格在大前天的平衡区的上部获得支撑，整体依然处于多头强势区，可**做多到 D-Shape 平衡区上轨 VAH**

        ![image-20260525002558752](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260525002558752.png)

      - **视角3：多转空剧本**

        - **背景**：整体大趋势依然是看涨，但昨天收了 **b-Shape** ，说明多头动能有所衰竭
        - **做空前提**：**大前天的平衡区上轨 VAH 被跌破**，即 **价格回到大前天的平衡区** 内，剧本由 b-Shape 多头延续 切换为 **D-Shape 均值回归**
        - **今日策略**：回调到 **大前天的 VAH** 做空，看空到 **大前天的 POC**，下跌到 **大前天的 VAL** 做多，看多到 **大前天的 POC**

- **VP 视角总结**

  ```
  1. 当前价格处于哪一个平衡区内，还是已经跳出了平衡区？
                      ↓
  2. 若在平衡区内部，则执行“均值回归”剧本（高空低多）
                      ↓
  3. 若已成功突破平衡区，则执行“趋势跟随”剧本回调介入
  
  随时根据价格对平衡区边缘的「接受」（重新跌回）或 「拒绝」（踩线弹开），在两个剧本之间切换
  ```

#### 004.价格路径与共振

* **价格路径（Price Path）**

  > 价格路径 = 当价格想要完成反转或穿越时，**可能遇到的阻力序列**

  * 趋势反转的条件

    > 必须**强力站在最后一个平衡区之上，且回踩不破**，否则**所有反弹都只是空头趋势的回调**
    >
    > ![image-20260525111153867](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260525111153867.png)

  * 价格穿越平衡区的路径（以空转多为例）

    ```
            ┌──────────────┐
            │     VAH      │ ← 第三阻力（最强）
            ├──────────────┤
            │     POC      │ ← 第二阻力
            ├──────────────┤
            │     VAL      │ ← 第一阻力
            └──────────────┘
                  ↑
             价格首先要突破这里
    ```

    | 阶段 | 价格行为                     | 判断           | 操作                                  |
    | :--- | :--------------------------- | :------------- | :------------------------------------ |
    | 0    | 不破 **VAL**                 | 空头延续       | **做空** → 盘整区 POC（均值回归）     |
    | 1    | 突破 **VAL**，回踩不破       | 确认回到平衡区 | 切换剧本，**空转多** → 目标 POC       |
    | 2    | 突破 **POC**，回踩不破       | 确认强势       | 继续 **做多** → 目标 VAH              |
    | 3.1  | **①** 到达 **VAH**，遇阻回落 | 仍在平衡区内   | **做空** → 目标 POC（均值回归）       |
    | 3.2  | **②** 站上 **VAH**，回踩不破 | 确认突破平衡区 | 继续 **做多** → 目标 下一个平衡区 VAL |

    * **①** 到达 **VAH**，遇阻回落是高概率做空机会，因为整体大背景是空头趋势，且价格处于平衡区上轨。此时若在 VAH 看到**小周期结构转空**或订单流卖盘介入，是一个**极高概率的右侧做空机会**

  * 价格路径的核心思维

    * **任何时候都要有 VP 视角**，这对判断方向和确定指引位至关重要

* **共振（Confluence）**

  > **共振 = 多个平衡区的关键位重合的地方** = **强关键位**
  >
  > ![image-20260525115531049](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260525115531049.png)

* **从未被回测过的关键位（Virgin Level）**

  > 从未被回测过的关键位 = **强关键位**
  >
  > ![image-20260525115641526](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260525115641526.png)

  > 除共振区外，概率最高、反应最敏锐的位置，是**从未被触碰过的关键位**（如：从未被回测过的 **Virgin VAH** 或 **Virgin POC**）
  >
  > 因为这些位置堆积了大量历史未成交的订单和套牢盘，当价格第一次触及它们时，往往会产生极其迅速且剧烈的排斥（反转）反应

- 实战建议

  > 一个成熟的交易员，不需要在每一个杂乱的位置频繁交易，只需要找到以下**3类高概率位置**并静待信号

  | **优先级** | **关键位类型**             | **核心实盘逻辑**                                     |
  | ---------- | -------------------------- | ---------------------------------------------------- |
  | **TOP 1**  | **多区共振区**             | 多个平衡区边缘或 POC 重叠的矩形区，阻力/支撑效能翻倍 |
  | **TOP 2**  | **从未被触及的 POC**       | Virgin POC，首次触碰的弹开概率极高                   |
  | **TOP 3**  | **从未被触及的 VAH / VAL** | Virgin VAH / VAL，代表极度失衡后的第一道强力拦水坝   |

  > **核心心法**：时刻保持全局观——“知道价格当前在哪一个平衡区，正在前往哪一个平衡区”

#### 005.订单原理

* **订单匹配原理**

  * **当前价格**：市场中**最后一笔撮合成功的交易发生的位置**

  * **市价单（Market Order）—— 主动订单**：急于立刻成交，直接吃掉盘口现有的挂单

    > **只有主动订单才会推动价格变化**

  * **限价单（Limit Order）—— 被动订单**：挂在订单簿（DOM）上不急于成交、等待被市价单匹配的单子

  * **成交量（Volume）** = 主动买入量 + 主动卖出量（成交量一定来自主动市价单的参与）

  * **流动性（Liquidity）** = 被动订单的厚度，决定了价格移动的难易程度

    > 挂单越厚，流动性越好，价格越难被推动
    >
    > 挂单越薄，价格越容易产生跳空或快速滑点

* **订单簿（DOM）中“流动性墙”**

  * **流动性墙**：订单簿上某个价位堆积的巨额限价挂单（如 98 手大单），形成一堵阻碍价格运动的“流动性墙”

  * **流动性墙的意义**（在不考虑欺诈挂单的前提下）

    ```
                                    流动性墙
                                       │
             ┌─────────────────────────┼─────────────────────────┐
             ▼                         ▼                         ▼
       【1. 磁铁引力效应】       【2. 机构大资金兴趣区】     【3. 价格阻力/交互区】
        吸引价格向其靠近，         这极有可能是主力机构      多头想攻克此位，必须付出
      大概率会主动去把它打掉       真正感兴趣的潜在反转位     成倍的主动买单，易剧烈交互
    ```

* **订单簿实战**

  * 错误做法 ❌：看到订单簿有巨额限价挂单，就提前在流动性墙的位置布局

    > 流动性墙具有欺骗性：①Spoofing（虚假挂单操纵） ②瞬间撤单（Cancel）

  * 正确做法 ✅：**不要去猜某个位置会不会产生反应**，**而是等反应出现之后，再去布局交易**

* **核心原则**：了解订单簿知识即可，不要拿来做单

#### 006.吸收与补仓

* **吸收（Absorption）**

  > 订单簿的限价单（被动订单）非常厚，以至于**完全阻挡并消化**了大量市价单（主动订单）的猛烈进攻
  >
  > > 主动订单的动能被被动订单"吃掉"

  * **足迹图（Footprint）上，吸收通常表现为“量价背离”**

    ![image-20260526121231959](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260526121231959.png)

    1. 场景一：**顶部/底部反转中的吸收**（以上涨为例）

       * **盘面**：一波多头阳线连续拉升 → 最顶部的 K 线里打出了**极其庞大的主动买单（大 Delta 阳线）**  →  随后价格不仅没有继续向上飙升，反而收出一根大阴线，并成功跌破了刚才高额多头订单聚集的区域
       * **逻辑**：多头疯狂地使用市价单买入，但空头主力在空头关键位挂了更海量的限价卖单（冰山单/限价墙）。多头的冲锋被全部吃掉，多头资金耗尽后，空头一发力（主动卖单打出），价格随即反转

    2. **场景二：趋势延续（中继）中的吸收**

       > ⚠️ **重要观念纠偏**：吸收不一定总发生在拐点（反转）中，也经常作为**趋势中继**出现

       * **盘面**：一波多头阳线连续拉升 → 在某根阳线的**中间或底部**，看到了非常突出的主动卖单（大额空头订单） → 但 K 线依然收阳，且价格继续向上运行
       * **逻辑**：上涨途中，有散户或逆势盘在疯狂用市价单砸盘（主动卖出），但**多头大资金的限价买单（被动接盘）更强**，把所有抛压被全部吸收，多头行情延续

* **机构补仓（Reload）**

  > 大资金因资金体量过于庞大，为了防止自身订单对市场造成严重的冲击（滑点），采用分批建仓的策略

  ```
                        机构分批建仓  
                            │
            ┌───────────────┴────────────────┐
            ▼                                ▼ 
           头仓                              补仓
                                             │
                            ┌────────────────┴─────────────────┐
                            ▼                                  ▼
                  【形式1：左侧限价单补仓】            【形式2：右侧市价单补仓】 
                   (Price/Limit Order)                  (Market Order)
                 表现为：回调至关键位时的【吸收】      表现为：突破关键压力位时的【突破单】
  ```

  * **识别机构补仓**（以多头为例）

    ```
    阶段1: 多头趋势确立
            ↓
    阶段2: 价格回调到关键位（POI如共振、从未被回测过的关键位）
            ↓
    阶段3: 关键位出现吸收
            - 足迹图显示大量主动空单打出
            - 但价格止跌，因为主动空单被多头限价单吸收 
            - 随后多头主动订单打出，价格反转
            ↓
    【判断】→ 多头趋势发起者在此进行了第一次补仓（Reload）
            ↓
    阶段4: 价格再次突破到前高/压力位
            - 突破压力位瞬间，足迹图显示大量主动多单打出，价格极速上冲
            ↓
    【判断】→ 第二次补仓（突破单形式）
    ```

* **为什么吸收是订单流课程最核心、最具有实战威力的逻辑？**

  * 因为**吸收是识别补仓的关键信号**，而大资金补仓的位置，就是我们入场跟随的最佳时机

#### 007.大单的真正含义

* **大单背后的真相**

  ![image-20260526122340613](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260526122340613.png)

  * **误解**：足迹图上，当某一价格突然显示巨额大单时（例如满屏的主动买方大单），大多数人的直观反应是“多头太强了，要暴涨”

  * **原理**：根据订单匹配原理，市场上的每一笔成交，都必须由主动市价单和被动限价单共同完成，即

    > 一笔多头大单 = 狂热的主动市价买单 (Market Buy) + 海量的被动限价卖单 (Limit Sell)

  * **结论**：足迹图上的任何大单都同时包含两层含义

    1. **主动方**：在猛烈地**推动**价格
    2. **被动方**：在该位置建立了坚固的防线，正在提供海量的流动性进行**承接**

    * **大单只能证明对手（承接盘）的存在，但无法直接说明哪一方更强。**
    * **“大单本身并不是信号，只有大单之后的交互结果才是信号，因此不能一看到大单就盲目追单”**

* **判定大单胜负的3个维度**

  ![image-20260526125025306](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260526125025306.png)

  ```
                              大单胜负研判三步法
                                     │
           ┌─────────────────────────┼─────────────────────────┐
           ▼                         ▼                         ▼
      【1. 看位置】             【2. 看后续结果】           【3. 看趋势环境】
    是否在关键位附近？           大单被顺势延续，还是        是顺势大单被承接，还是
    大单是不是诱敌深入？          被反向大单暴力吞没？        强趋势中的反向插针吸收？
  ```

  1. **看位置**

     - **逻辑**：大单所处的位置直接决定了它的性质
       - 关键位附近的大单大概率是吸收，可能反转
       - 非关键位附近的大单可能性很多，参考意义不大
     - **现象**：当价格一路上涨，到**强空头关键位**时，足迹图上突然爆发出**多头大单**
     - **解读**：千万不要误以为是多头要突破了，这极大概率是空头机构挂的海量限价卖单（Limit Sell）**承接**了多头市价单。若随后价格滞涨，说明空头承接成功，这里是空头大资金真正感兴趣的参与区，极易反转

  2. **看后续结果**

     - **逻辑**：主动发力的一方，必须拿到它应得的结果
     - **现象**：当价格一路上涨，在顶部出现**多头大单**，但后续一根或几根 K 线**没有产生任何上涨延续**，反而被**空头大单**配合一根大阴线**反向吞没**
     - **解读**：多头的倾力一击被空头的限价单全部默默**吸收**。主动方力竭，被动方转为主动反击。这就是最标准的**右侧反转迹象**

  3. **看趋势环境**

     - **逻辑**：不同趋势背景下，反向大单的含义完全不同

     - **现象**：当价格一路上涨，突然快速回踩，回踩的底部伴随着长长的下影线，并打出了**大量的空头大单**，随后价格又迅速收回并继续向上拉升

     - **解读**：这**绝不是**多头趋势的结束，而是多头在回踩时，在关键位布局 **限价多单** 进行疯狂的 **加仓**

       > 即在强趋势中，反向大单 + 影线 = 趋势延续

* **大单真正的意义**：显示**谁在主动推动价格**，**谁在被动承接**

#### 008.Delta、MD、真实供需区

* **Delta**

  * **Delta** = 主动买入量 - 主动卖出量

    * **正 Delta（绿色）**：主动多头更强
    * **负 Delta（紫色）**：主动空头更强

  * **Delta Profile（Delta 分布图）**：用于展示一个波段的 Delta

    > ⚠️ **为什么不要死盯着单 K 的 Delta？**
    >
    > 要有 **波段视角（宏观视角）**，过度关注单 K 的微观 Delta，视野极易被锁死在日内的杂乱波动中

* **MD （Max Delta）**

  * **定义**：一段 Delta Profile 中，**最大的多头Delta或最大的空头Delta所在的位置**

  * **用途**：将MD位当作关键位使用

  * **实战**：若一个波段的 Delta Profile，**最大的空头 MD **与**最大的多头 MD **距离很近，说明这里是多空激烈交互的位置，是个S/R，一旦这个区域被突破并回踩站稳，则 **趋势反转**

  * **案例：下跌趋势中，打出巨大的负Delta，其后不同的K线表现，有不同的意义**

    ![QQ_1779771536991](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/QQ_1779771536991.png)

    1. 位置一：趋势中的放量
       * 表现：打出巨大的负Delta后，价格【明显延续】
       * 本质：空头主动发力的成本区（供给区），也是多头放弃的区域
       * 实盘：【做空关键位】，回踩这里，做空
    2. 位置二：趋势终结处的放量
       * 表现：打出巨大的负Delta后，【无延续】并被迅速向上反包
       * 本质：空头末期情绪释放，遭遇主力大规模【吸收】
       * 实盘：【做多关键位】，回踩这里，做多，在位置一的巨大的负Delta处止盈

* **真实供需区（Supply/Demand Zone）**

  * **裸 K （Price Action）供需区判断方法**：极限OB

  * **足迹图供需区判断方法**

    ![image-20260526130749408](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260526130749408.png)

    1. **必须包含一个明显的 MD**：在 Delta Profile 上有极长、极突出的单向 Delta 柱

       > 供给区对应极长紫柱负 Delta，需求区对应极长绿柱正 Delta

    2. **必须突破时伴随“失衡”**：价格快速突破该盘整区域（在足迹图上形成横向的多空失衡），K 线成交量不需要很大，但 Delta 的方向性必须单一

    3. **必须有明显的“趋势延续”**：突破之后，行情拿到了结果，走出了可观的单边延续，证明了这一方彻底打赢了胜负

#### 009.趋势与订单流

* **传统价格行为 vs 订单流的趋势研判**

  * **传统价格行为（PA/裸K）**：依赖 K 线高低点结构

    > **例：上涨趋势**：高点抬高，低点抬高。预期后续突破前高，且不跌破前低

  * **订单流（Order Flow）**：观察大单的 **获利** 与 **被套** 状态，捕捉趋势反转的临界点

    > 💡 **灵魂一问**：**“当前多空双方，谁在赚钱？谁被套了？”**

* **如何界定 获利 与 被套**

  * **多头订单流（Bullish Order Flow）**
    - **现象**：在 K 线下影线上打出大量空头大单（市价卖单），但随后 K 线收高并一路上涨
    - **本质**：空头大单全部被多头限价单吸收，**空头被套（处于亏损状态）**；而上涨途中的多头大单全部**处于赚钱状态**
  * **空头订单流（Bearish Order Flow）**
    - **现象**：在 K 线上影线上打出大量多头大单（市价买单），但随后 K 线收低并一路下跌
    - **本质**：多头大单全部被空头限价单吸收，**多头被套（处于亏损状态）**；而下跌途中的空头大单全部**处于赚钱状态**

* **订单流做单步骤**

  * **【案例一：多单集群被套，确认转空】**

    ![image-20260526161937884](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260526161937884.png)

    1. **多头核心防线**：价格一路上涨，在足迹图上留下了一个 **186手多头大单** 以及一个**多头订单集群**。这2个位置是多头的最强防线。**只要这里没跌破，订单流就依然由多头控制**
    2. **空头发力**：随后回调，在上方打出了 **49手、195手、78手等空头大单**。虽然中途多头抵抗收了两根阳线，但在 78手空头大单处受阻（未被解套），随后一根大阴线下砸
    3. **判定胜负（转空点）**：这根大阴线实体收下去后，**186手 和 多单集群 被彻底套牢**，而上方的空头大单全部进入**赚钱状态**。此时，订单流 **由多转空**
    4. **交易计划**：如果大周期是空头趋势，则可在刚才空头发力的关键位（如 78手、195手附近）划出空头关键位，等待价格回踩并配合入场模型做空

  * **【案例二：多头强攻失败，破颈线位入场】**

    ![image-20260526165850033](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260526165850033.png)

    1. **多头核心防线**：价格一路上涨，在足迹图上留下了一个 **130手和 116手的多头大单** ，这是多头的最强防线
    2. **多头吸收入场**：随后回调，在多头的最强防线产生 **48手 和 81手** 吸收，并收阳线，多单入场，但随后一根强势大阴线砸穿多头防线（系统内损单）
    3. **空头发力**：这根大阴线实体收下去后，**130手 和 116手的多头大单 被彻底套牢**，上方**48手 和 81手**的空单全部解套，进入**赚钱状态**。此时，订单流 **由多转空**
    4. **交易计划**：如果大周期是空头趋势，则可在刚才空头发力的关键位（如 40手、81手、61手、52手空单集群附近）划出空头关键位，等待价格回踩并配合入场模型做空
    5. **多头的反抗**：随后在空头关键位，多头再次打出 **120手大单**，但价格却无法上涨，转而进入盘整，后续盘整区的底部再次打出 **50手多头大单**，直到一根阴线实体跌**破盘整区的 50手多单**，**多头大单再次被套**，订单流的回调也 **由多转空**
    6. **交易计划**：在**被套多头的关键位挂单做空**

  * **【案例三：不做没有确认的反转单】**

    ![image-20260526171154726](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260526171154726.png)

    1. **订单流防护罩**：在上涨途中，只要我们画出的“最后一个多头大单位置 / 多头失衡区”，**没有被空头用实体 K 线强势跌破并将其套牢**，就没有任何理由去做空
    2. 市场如果始终不跌破多头防线，订单流就永远不会转空。这个严格的逻辑可以**直接帮我们过滤掉 90% 以上盲目抄顶的自杀式交易**

* **总结：订单流做单3步骤**

  1. **第一步：判断当前订单流状态**：谁在赚钱？谁被套牢？
  2. **第二步：画出波段的关键防守位**：最重要的大单位置 或 订单集群 或 Delta，
  3. **第三步：确认订单流转向并执行**：观察价格触及防守位时的反应
     1. **强势跌破**：则多头被套，订单流转空，在空头关键位挂单 或 等右侧入场模型
     2. **踩线弹开**：则多头防守成功，订单流依然是多，等金K顺势做多

#### 013.压刺剥头皮系统

> 专为 NQ 的 F1 设计的 **机械化右侧系统**
>
> 当价格来到 **S/R** 或 **某个关键位** 时，首先找 **吸收 + 底分型**，随后在**上涨过程**出现 **上影线pinbar（吸收加分）**，记住这个上影线的高点不能高于前方的高点，此时如果止损足够小，就可以在上影线挂突破单进场
>
> 完整逻辑：在关键位 -> 空头被吸收 -> 尝试上涨碰到压力位，多头暂时也被吸收（出上影线），若多头继续发力，则可跟随多头动能上车

* **S/R 区域**

  - **形态要求**：有明显的强力突破（好大哥），①波段高/低点突破 或 ②震荡区间边沿突破 均可
  - **突破要求**：好大哥突破时必须 **带动能、有失衡**
    - *禁忌（直接放弃）*：插针微幅突破，随后立刻陷入窄幅横盘震荡，此 S/R 无效
  - **使用寿命**：每个 S/R 可以用2次，第3次很可能就失效了
  - **深度回调的处理**
    - *过滤规则*：若回调过深，直接把之前的多头突破结构给跌破了（插针太深或肉眼可见转空），说明多头防线失效，直接**放弃**
    - *可接受情况*：若是插针瞬间拉回，收长影线，即被强势拒绝，并在 S/R 附近快速形成底分型，这种深度回调可以接受
  
* **订单流入场模型：压刺与双吸收**

  * **压刺**

    ![image-20260604180021378](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260604180021378.png)

    1. **第一步（左侧）**：价格砸向 S/R，在底部爆出空头大单被吸收（Delta Profile 或足迹图低点显示红大单），但价格反而止跌收高，形成 **带吸收的底分型**

       > 确认第一次空头发力失败

    2. **第二步（右侧）**：在随后的上涨腿中，出现一根 **长上影**（最好是带多头套单的阴K）

       > 表示 **空头在这里试图砸盘，并成功把价格压出上影线**

    3. **第三步（挂单）**：这根 **长上影** 就是 **压刺信号**，直接在长上影的上方挂 **买入突破单**，止损在**压刺K底部 或 波段最低点**

       > 若后续价格能够向上突破，并吞没该上影线，则确认第二次空头发力再次失败，并沦为被套盘，我们可借此吞噬空头的动能上车

  * **双吸收（激进形态）**

    ![image-20260604180230925](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260604180230925.png)

    * **第一步（左侧）**：价格砸向 S/R，在底部爆出空头大单被吸收，形成 **带吸收的底分型**

    * **第二步（右侧）**：在随后的上涨腿中，等待空头陷阱，但是并没有出现，而是**二次探底**，在  S/R 附近砸出第2个 **带吸收的底分型**

    * **第三步（挂单）**：在第2个 **带吸收的底分型** 的上方挂 **买入突破单**

      > 同一位置出现两次强烈的吸收防御，具备极高的概率优势，可省去寻找上影线的步骤

- **执行清单**

  - **环境验证**

    - 是否美盘AM时段（9:30 - 11:30）：其余时段噪音多、动能弱，直接放弃

    - 是否是个好大哥（带displacement缺口）（**重要**）

      > 1. 大哥的突破没有跟随、粘粘糊糊，直接放弃
      > 2. 盘面处于无方向的宽幅震荡，没有任何 S/R，直接放弃

    - 是否已回踩到 S/R 区域

    - 是否 S/R 区域已失效（在这个 S/R 止损过）

      > 若在该 S/R 区域**止损了一次**，则在前高与第一步吸收反转K之间的区间里不再做任何单子，直到突破该区间，走出新大哥，再找 S/R ，等回调，等吸收反转K，等压刺，再挂单

  - **信号确认**

    - 是否出现第一次空头失败（ S/R 区域出有吸收的反转K）

    - 是否在反转途中出现第二次空头发力（反转途中出压刺K）

      > 若是个 **十字星**，而不是 **上影线**，则不能证明是空头发力，这不是压刺，直接放弃

    - （加分项）是否在压刺上影线有多头套单

  - **可执行性**

    - 是否压刺长度合理（止损可接受）：压刺区间超过 **20 点**，则风险过大，直接放弃
    - 是否压刺前未破前高（结构仍有效）：若已破前高，则没了利润空间，不要高位追单，直接放弃
    - 是否压刺后3根K线入场：若长时间徘徊，则说明动能消失，直接放弃

  - **风控**

    - 是否止损在压刺低点（看图更清晰）
    - 是否止盈3R
    - 是否当日亏损未达2R（未熔断）

- **资金管理、出场与指盈**

  - **入场**：**严禁市价追单**，一律使用右侧突破挂单，让行情带我们入场
  - **止损**：严格放在压次或底分型的极值低点（若空间极小只有几个点，则可灵活放大防守至结构低点）
  - **指盈**：固定看 **3R**，也可根据个人舒适度调整为 2R
  - **推保**：由于NQ波动剧烈，若进场后迅速走出一段利润，要及时推保
  - **日熔断**：单日亏损 **2 笔到 3 笔**，单日累计止损达到 **60 点**，必须立刻关电脑下班，严格限制回撤

- **提问**：因规则卡得太死，或因回踩不碰 S/R，有时一天可能一单都没有，要不要优化进场？

  💡 **最好不要**

  1. **不要过度优化系统**：这套系统经过严格回测，在规则卡死的情况下胜率 **> 70%**，配合 3R 的盈亏比，优势已经极其巨大
  2. **大不了当天没有交易，这非常正常**：交易员爆仓、心态爆炸的根本原因，99% 都是因为**过度交易（Over-trading），不要盲目增加交易频次**
  3. **把交易变成无情绪、机械化的工作**：不要花时间去主观预测当天的市场偏见，到地方出形态就做，不出就等着。这能帮你避开了所有的震荡绞肉机，能让你在市场中活下去

                      【优先级 3：区间最高/最低点对应的 OB (订单块)】
  ```

  * **未被测试的 POC**

    - 内包K线中的底分型同样有效
    - POC 被拿掉，则不作参考（**永远只关注最新且未被测试的POC**）

  * **真正供需边界 LVN**

    * 找到未测试的 POC 后，以其上方最近的一个**成交量谷底（LVN，低成交量节点）**为上沿，下方最近的一个**成交量谷底（LVN）**为下沿，框出的矩形区域即真实供需区

    - 价格触及 LVN 时发生反转的概率最高（这综合了 OB 与最大筹码峰的共同优势）

  * **变体：双重分布**

    * 若 H1 K线内部包含上下两个极大的筹码峰（等同缠论的两个小中枢），则这两个位置同时有效

  * **反转 K 替代**

    * 若没有标准顶底分型，有强力的**看涨/看跌吞没、启明星**等反转金 K，其未测试 POC 同样可用

* **操作逻辑**

  > 本策略的精髓 **不盲目赌反转，而是确认新趋势发起后，顺势上车**

  * **持仓逻辑（首选）**：
    - **做空**：在前一个“顶分型”关键位入空单，目标拿到**前一个“底分型”的筹码峰**
    - **做多**：在前一个“底分型”关键位入多单，目标拿到**前一个“顶分型”的筹码峰**
  * **持仓逻辑（备选）**
    - 若没有明显顶底分型，则 **固定风控 10 点 止损，25 点 止盈**
  * **关键位寿命**
    - 同一个关键位最多使用 **2 次**。通常第一次触及用于清理流动的清扫，第二次入场时往往能看得更远。
  * **推保**
    - 当 H1 走出一根明显的 **放量K** 后，由于 放量K 的起点不应被穿破，此时应立即推保

* 盘面突发：新趋势发起的两大交易变体

  > 当价格还没触及我们昨晚标好的关键位，在亚盘就直接发起了单边新趋势，仅有以下两个变体机会

  * 变体 A：扫单创出新低/新高 + 形成新分型
    * 价格拿掉了前一天的低点，随后在 1H 级别收出了一个**新的底分型**。
    * **操作**：立刻顺应这个新发起的趋势。标出这个新底分型 POC 上下的 LVN 区域，在回踩该区域时直接做多，目标看向上方的顶分型筹码峰。
  * 变体 B：实体强力突破前高/前低（无明显分型）
    * 价格没有给出明显的顶底分型，而是直接以**大阳/大阴线实体突破前高/前低**。
    * **操作**：立刻锁定这根“实体突破K线”自身的 **POC 位置**作为临时关键位，顺应这个强动能趋势直接追随做多/做空。

* 四大微观入场方式

  > 当 1H 价格精准触及我们标出的 LVN 框线区时，切入小周期（1分钟/5分钟），观察订单流 footprint（足迹图）给出的四种入场信号：

  | **入场方式**              | **核心盘口现象**                                             | **操作要领**                                                 |
  | ------------------------- | ------------------------------------------------------------ | ------------------------------------------------------------ |
  | **1. 盘整结构（最常见）** | 价格在关键位震荡，发生流动性清扫（猎取流动性）。             | 看到多头/空头前期的**堆叠失衡被彻底填补或跌破**后，顺势进场。 |
  | **2. V型反转（V反）**     | 价格触及关键位迅速弹开，在反转顶点爆出大单。                 | 关注后续价格对这个**多空激烈竞争大单位置**的测试，若被拒绝则市价切入。 |
  | **3. 激进吸收**           | 价格刚触及关键位，足迹图立刻显示出大量的**主动单被限价单吸收**。 | 胜率约为 50%。可直接挂单在关键位或在吸收出现的瞬间市价（施加）入场。 |
  | **4. 通道式反转**         | 价格呈通道形缓慢阴跌或阴涨。                                 | **【重点警告】这种形态最容易被直接打穿，老师日常操作中一般不做通道式反转。** |

  > ⚠️ **震荡与堆叠失衡的过滤防守：**
  >
  > 如果行情在关键位持续震荡或出现大量内包K线，中间产生的小失衡不断被后续K线无情填补，**此时绝不能入场**。必须耐心等待一次流动的清扫，并看到产生**被市场尊重、未被填补的全新空头/多头堆叠失衡**时，才是最安全的鸣枪信号。

#### 004.日本蜡烛图

1. 影线 & 实体

   1. 影线：被拒绝的价格区，价格不愿意停留，影线越长，则受阻越明显

      > 若后续K线再次回测影线并再次被拒绝，则趋势大概率延续

   2. 实体：被接受的价格区，价格愿意停留，实体越长，则一方力量的控制权越强

   3. 双影线（上下都有）：多空双方都有拒绝，力量均衡

2. 单根K线内的PO3（以阳线为例）

   1. 开盘前，盘整 = A（积累）
   2. 开盘向下形成最低价 = M（操纵/假突破）（形成下影线的过程）
   3. 随后上涨形成实体 = D（派发/趋势）
   4. 最后小幅回调收盘（形成上影线的过程）

3. 单根K线内的三次交易机会（以阳线为例）

   > 一根日线K线，当天通常至少有三次交易机会

   1. 第一次机会（M阶段）：形成下影线过程（开盘价下方），小周期转多信号 → 做多；要等小周期结构，否则可能是真跌
   2. 第二次机会（D阶段）：价格站上开盘价，确立多头趋势，回踩不破开盘价 → 做多；
   3. 第三次机会（收盘前回调）：形成上影线过程，触及高位关键位，小周期做空信号 → 做空

4. 一些Tips

   1. 等收线：不在K线收线前急于进场，**未收线前的价格行为都是暂时且未确认的**
   2. Pinbar颜色：长影线最重要，关键位的长影线最重要，阳线或阴线均可
   3. Delta背离：①价格收阳 ②Delta为负（卖方主导），则可能买方枯竭，反转概率增加（必须结合关键位 + 订单流数据）

#### 005.市场结构

1. 真 MSS：只有在 **价格触及高周期POI** 时，结构才具有分析价值，中间上蹿下跳的 MSS“，更大概率是震荡，是杂音

   > 结构来自关键位，井服务关键位

2. 假 MSS：价格打到高周期POI后，看似出反向结构，但 **推进无力，突破不带量，没速度，突破后立即收回**。随后小周期迅速走出反向的反转结构

   > * 假 MSS 本质上就是 PO3 的 **M（操纵扫损）**
   >
   > * “无假破，不做单”是本系统的核心
   > * 假破非但不是陷阱，反而由于其不带浮亏且运行极其顺畅，是最完美的右侧入场位

#### 006.直播答疑

1. 传统 OB 挂单 VS 幻焰模型

   1. 传统 OB 挂单：极其容易遭遇假破（Manipulation）
   2. 幻焰模型：不预测支撑位一定能守住。相反，系统期待价格砸破支撑位，完成流动性猎杀（清扫），并在小周期（F1/30s）出入场模型

2. 主流案例：大周期定偏见，小周期找模型

   1. 第1步：筑底验证。价格触及大周期多头关键位 ➔ F5，导致最后一波下跌的最近高点被反向上破 ➔ 确认空转多结构
   2. 第2步：锚定诱因。多头确认后，在 F1 标出明显的有效回撤低点（作为流动性池/诱因 IDM）
   3. 第3步：假破入场。价格回调，“故意”下扫拿掉该有效回撤点 ➔ F1出入场模型

   > 这里空转多的核心不是单纯的 F5 结构突破，而是 **大周期关键位 + F5 结构突破，共同确定了多头偏见**，如果没有大周期关键位支撑，F5 结构突破再漂亮，也没有理由盲目做多

3. 例外案例：外部结构过大，可考虑内部结构

   1. 内部结构走出 **“N字结构”**（证明多空某一方至少连续两次发力），可切入小周期，寻找内部的有效回撤点，等待被清扫，介入
   2. 做内部结构，止盈必须保守，通常拿到高周期反向关键位的50%，就要平仓或做推保
   3. **禁忌行情**：**坚决不做通道式上涨/下跌（没有干净回踩拿流动性的慢推行情）**。若持仓中发现行情走成通道，立刻出局

4. 关于美盘开盘：市场往往会借助开盘动能把亚欧盘积累的弱高点/弱低点一次性扫掉（猎杀流动性），然后瞬间爆发出反向趋势。核心是**不盲目左侧挂单，而是画好线，等开盘清扫出反应后再进场**

#### 007.流动性概念

![image-20260625153842814](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260625153842814.png)

1. **流动性**：本质是**订单簿上待成交的限价单厚度**

   1. **被动流动性（限价单）**：订单簿上的挂单，它们**不推动价格**，而是挂在那里作为“供给方”，等待并吸收市价单

      > 流动性好意味着每个价位的限价单数量厚

   2. **主动流动性（市价单）**：代表急于立即成交的“需求方”

      > 市价单会**消耗**订单簿上的限价单，**它是推动价格移动的唯一力量**

   3. **止损单**：看似是限价单，但其实不是订单簿中的挂单，而是托管在交易所后台，等待价格触及，立即砸向市场的市价单

      > 因此，散户的止损单是潜在的主动流动性提供者

2. **失衡**：当某一价格区间的限价单非常稀薄时（比如，白天流动性差），只要极少的市价单入场，就能连续吃掉多个价位，推动价格快速移动。这种单边压倒性的快速移动产生的区域被称为**低效率市场**，即失衡，裸 K 表现为 FVG

   1. 失衡不是双方均衡博弈后的结果，价格后续会填补这一区域，原因是（依据拍卖理论）

      ![image-20260625162719644](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260625162719644.png)

      * 2个平衡区之间区域就是失衡区
      * 平衡区是价格愿意停留的地方，失衡区是价格不愿意停留的地方
      * 市场会在平衡区两边挂单，期待价格回到平衡区里面，而平衡区的边缘也是失衡区的边缘，这里是 **成本最低、性价比最高** 的吸筹位置
      * 同时，回调填补失衡的操纵行为也会触发散户的惊恐止损单（主动卖单），进一步帮助机吸筹

   2. 周开盘缺口（Weekly Gap）与日开盘缺口（Daily Gap）与 FVG 一样，是更高周期的失衡

      ![image-20260625161712401](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260625161712401.png)

3. **机构建仓/派发策略**

   1. 为了控制建仓成本/提高派发效率，机构会寻找流动性充足的区域
   2. 建仓/派发位置：散户止损密集区和突破单密集区 S/R
   3. 建仓/派发策略：将大单拆分成冰山单，吸收散户的止损单

4. **机构建仓的足迹图特征**

   1. 量价背离：价格触及 S/R 后，成交量极度放大，但是价格推进受阻，表明冰山单在源源不断的吸收
   2. MD 爆发：如极大的正 Delta（主动买盘极强），但随后 K 线却收成阴线，说明主动买盘全被被动限价卖单吸收并反向压制

5. **订单薄陷阱 Spoofing - 诱单墙（以上涨为例）**

   ![image-20260625155631143](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260625155631143.png)

   1. **手法**：主力在当前价格上方故意挂几百手巨额限价卖单（散户通过 ATAS 订单簿能清晰看到一面“橙色大单墙”）
   2. **散户心理**：以为这有超强阻力，纷纷在大单墙下方抢跑挂空单
   3. **猎杀**：当价格真正逼近这堵墙时，主力瞬间撤掉所有买单，并在原价位下方反向挂冰山买单。失去阻力的抢跑散户被瞬间套牢，价格崩盘式上涨

6. **传统价格行为 VS 订单流 对S/R的态度**

   1. Price Action：价格测试某一价位的次数越多，说明这个价位的阻力越强
   2. FootPrint：价格测试某一价位的次数越多，说明这个价位的限价卖单**被市价单消耗得越多**，这堵墙变得越来越薄。未来某个时刻，当挂单被彻底吃光，价格将直接突破。因此测试越多，越要谨慎

#### 008.流动性应用

1. **外部流动性（ERL - External Range Liquidity）**：价格的目标点（前高/前低、等高/等低、明显盘整区的上/下沿）

   > 这些位置是散户止损与突破挂单集中的区域，因此具有“吸引力”

2. **内部流动性（IRL - Internal Range Liquidity）**：是价格回补失衡，市场修正自己，重新恢复平衡的过程（FVG / 缺口）

3. **价格运行逻辑：** 从外部流动性，到内部流动性补充订单，再到外部流动性

4. **高胜率关键位**：上方有一个 IDM 的关键位，才是高胜率关键位

   > 并非所有的有效回撤都具备交易价值

   > 案例：价格从高位 ERL 回调 ➔ 下跌并**拿掉 IDM** ➔ 在拿掉 IDM 后 **刚好踩住 IRL（失衡关键区）** ➔ 机构完成吸收。此时小周期（F1/F5）一旦给出反转模型，就是胜率最高、盈亏比最恐怖的顺势跟随单

5. **高胜率模型（从高阻力流动性出发，目标都是低阻力流动性）**

#### 012.拍卖理论 Auction Market Theory

1. **拍卖逻辑**

   1. **视角**：市场是一个拍卖场，目的是寻找买卖双方都同意的价格来成交

      > 不以“结构”或“趋势”来看待市场，而是以“平衡”与“不平衡”来理解市场

   2. **价格接受**：价格喜欢在某个区域长时间停留，则这里会产生成交量堆积、反复换手，表现为**横向交易区间**（买卖双方力量均衡），代表市场找到了公平价格

   3. **价格拒绝**：价格一路下跌/上涨，突然产生急涨/急跌的V反，不愿意在此停留，表现为**长影线**，代表市场不接受这个不公平价格（因太便宜没人卖，或太贵没人买）

   4. **运行机制**：市场永远在【平衡 ➔ 不平衡（失衡突破） ➔ 新的平衡】之间不断循环

2. **价值区 Value Area**

   1. **高斯分布**：统计学中，约 **70%** 的样本集中在中间（均值附近），两边极端值（过高/过低）会向均值回归
   2. **价值区**：将高斯分布旋转90度，对应成交量占  **70%** 的价格区
      1. 当价格打到价值区两端时，大概率产生**拒绝（支撑/阻力）**，向中间成交量最高的区域回归

3. **成交量分布图 Volume Profile - VP**

   1. **VA (Value Area)**：价值区（当天70%成交量的区域）
   2. **VAH (Value Area High)**：价值区高点（支阻）
   3. **VAL (Value Area Low)**：价值区低点（支阻）
   4. **POC (Point of Control)**：控制点（价值区内**成交量最多的价格位**），具有强大的磁吸作用
   5. **HVN (High Volume Node)**：高成交量节点（平衡区/价格接受区）
   6. **LVN (Low Volume Node)**：低成交量节点（不平衡区/价格不接受区/真空区，即**FVG/失衡**）

4. **三大 VP 形态**

   1. **P形态（上涨）**：成交量集中在整个分布的**上沿**，即价格在高位横盘被市场接受（连续P = 趋势延续）
   2. **b形态（下跌）**：成交量集中在整个分布的**下沿**。即价格在低位横盘被市场接受（连续b = 下跌延续）
   3. **D形态（震荡）**：成交量分布在**中间**。即市场目前处于标准的区间震荡，多空达成共识

5. **VP 视角下的趋势、震荡、反转**

   ![image-20260713125713958](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/image-20260713125713958.png)

   | 市场状态 | VP结构                           | 拍卖行为               |
   | -------- | -------------------------------- | ---------------------- |
   | 上升趋势 | 连续P形态 + POC上移              | 接受更高价格           |
   | 下跌趋势 | 连续b形态 + POC下移。            | 接受更低价格           |
   | 横盘震荡 | 连续D形态                        | 接受固定价格           |
   | 反转     | 最后平衡区被拒绝 + 新POC反向移动 | 拒绝旧价格，接受新价格 |

   

6. **VP 实战（多转空）**

   1. 关注美盘 VP：NY 09:30 - 16:00（美盘成交量最大，主力博弈最真实）

      > **VP与时间周期无关**：无论 F1、F5、F30，当天的成交量分布形态是完全一样固定的。建议在 **F5** 观察，既能看清大方向，又能看清内部细节结构

   2. 画关键位：① 昨日VP ② 昨日 VP 上下未触碰的 VP ③ 3个月的 POC ④ 白天 F1 大波段的 MD

   3. 识别多转空

      1. 原趋势：连续 P 形态的上涨趋势
      2. 高位拒绝：价格涨到某一位置，因太贵，没有市价买单愿意接盘
      3. 反向寻找下一个买卖双方都愿意成交的区域，实体跌破前一个 P 形态的价值区下沿，并在下方横盘震荡，形成 b 形态，同时 价格回测当前价值区的 VAH 或 前一个价值区的 VAL 时寻找做空机会

7. **单 K 线 POC**

   1. 含义：单 K 线内部，产生成交量最高的那个价格横线
   2. 作用：**关键位**的入场信号
      1. 空头关键位出 ① 1根长上影，POC 在影线部分 ② 1根实体阴线，POC在顶部，收盘在POC下方。即高位有大量换手，但涨不动了，确认市场开始接受更低价格，可市价入场（左侧）
      2. 后续回调，测试上1根K线的POC，受阻，再次下跌，且 POC 收在下方，可市价入场（右侧）

   3. **绝不能孤立看信号**：不能一看到单 K 线 POC 在上方就盲目做反转。**必须先用大周期 VP 关键位**，当价格来到这些关键支阻时，再切到小周期看单 K 线 POC 和收盘价的相对位置，以此做右侧入场

8. **拍卖理论 VS 聪明钱理论（SMC）**

   | 拍卖理论                           | 聪明钱理论（SMC）                  | **市场行为本质**                                         |
   | ---------------------------------- | ---------------------------------- | -------------------------------------------------------- |
   | 两个平衡区之间的 LVN（低成交量区） | FVG（公平价值缺口）/ 失衡          | 价格一瞬间通过，停留时间极短的不平衡阶段                 |
   | HVN（高成交量堆积区）/ 平衡区      | OB（订单块）/ 盘整区间             | 机构与散户大量换手、达成共识的价值区                     |
   | 未完成拍卖                         | 构建等高点/等低点（EQH/EQL）流动性 | 该价位有人想交易但未被充分满足，价格必定会回来清理并测试 |
   | 完成拍卖                           | Manipulation                       | 向上/向下突破区间制造假动作，产生拒绝后反向开启真正趋势  |

1. Mac上构造 9:16 的环境

   > ![image-20260803124233172](https://raw.githubusercontent.com/jiangsai0502/PicBedRepo/master/img/202608031242253.png)
   >
   > 方法1：Keyboard Maestro 
   >
   > 1. Set Variable to Calculation，设置变量名 LocalAspect，值 9 / 11（可随时改）
   > 2. Resize a Window
   >    1. →  (水平位置 - 自动居中）：SCREENVISIBLE(Main,Left) + (SCREENVISIBLE(Main,Width) - (SCREENVISIBLE(Main,Height) * LocalAspect)) / 2
   >
   >    2. ↓ (垂直位置 - 顶部对齐)：SCREENVISIBLE(Main,Top)
   >    3. ↔ (宽度)：SCREENVISIBLE(Main,Height) * LocalAspect
   >    4. ↕ (高度)：SCREENVISIBLE(Main,Height)
   >
   > 方法2：Hammerspoon
   >
   > 1. 打开配置文件 `open /Users/sai/.hammerspoon/init.lua`，粘贴下方代码
   >
   >    ```bash
   >    -- 获取屏幕可用高度（扣除菜单栏）
   >    function getAvailableHeight()
   >        local screen = hs.screen.mainScreen()
   >        local frame = screen:frame()  -- 可用区域（扣除菜单栏和Dock）
   >        return frame.h
   >    end
   >    
   >    -- 设置窗口为 9:15 比例，高度占满屏幕
   >    function setWindowTo9x15(win)
   >        if not win then return end
   >    
   >        local screen = win:screen()
   >        local frame = screen:frame()
   >        local maxH = frame.h
   >        local targetW = math.floor(maxH * 9 / 15)
   >    
   >        -- 居中放置
   >        local newX = frame.x + math.floor((frame.w - targetW) / 2)
   >        local newY = frame.y
   >    
   >        win:setFrame(hs.geometry.rect(newX, newY, targetW, maxH))
   >    end
   >    
   >    -- 绑定快捷键：Ctrl + Alt + Cmd + R
   >    -- 绑定快捷键：Control + Option + Command + R
   >    hs.hotkey.bind({"ctrl", "alt", "cmd"}, "R", function()
   >        local win = hs.window.focusedWindow()
   >        if win then
   >            setWindowTo9x15(win)
   >            hs.alert.show("已设置为 9:15 📱")
   >        else
   >            hs.alert.show("没有聚焦的窗口")
   >        end
   >    end)
   >    
   >    -- 可选：一键设置特定App
   >    function resizeAppByName(appName)
   >        local app = hs.application.get(appName)
   >        if app then
   >            local win = app:mainWindow()
   >            if win then
   >                setWindowTo9x15(win)
   >                win:focus()
   >            end
   >        end
   >    end
   >    
   >    -- 为 Chrome 和 TradingView 单独绑定
   >    hs.hotkey.bind({"ctrl", "alt", "cmd"}, "C", function()
   >        resizeAppByName("Google Chrome")
   >    end)
   >    
   >    hs.hotkey.bind({"ctrl", "alt", "cmd"}, "T", function()
   >        resizeAppByName("TradingView")
   >    end)
   >    ```
   >
   > 2. Hammerspoon 顶部栏图标 Reload Config
   >
   > 3. 选中 App，control + option + command + r，即可设置成9:16
